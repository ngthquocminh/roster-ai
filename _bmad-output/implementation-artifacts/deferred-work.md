## Deferred from: code review of story-1.4 (2026-08-05)

- Pagination cursor isn't pinned to a `scenario_version`. Every paginated request (`get_tasks`/`get_workers`/`get_demand`/`get_constraints`) independently re-resolves "latest version"; the cursor is a bare integer offset carrying no version identity. If a new `scenario_version` is imported between two paginated requests for the same `scenario_id`, the underlying list being sliced changes silently — pages can skip, duplicate, or reorder records with no error surfaced. AD-4 exists specifically to prevent this class of "fact drift." [backend/adapters/postgres/scenario_projection.py:329-350,433-451] — resolved as a decision-needed finding on 2026-08-05: deferred, accepted as a known limitation. Fixture imports are a manual, governed operation (Story 1.1) with low real-world odds of racing a user's paginated browsing session; revisit (cursor pinned to `scenario_version_id`, rejecting a later page that no longer matches) if/when import cadence or concurrent-editing use cases change.

A malformed row today raises, but `api/main.py`'s global `Exception` handler already converts that into a proper RFC 7807 500 with no data leakage, and the raw fixture is governed/validated at import (Story 1.1). [backend/adapters/postgres/scenario_projection.py:88-95,237-243] — pre-existing safe failure mode, not reachable via governed fixture import.
- `_horizon` doesn't validate `end >= start` or that exactly one `Scenario Range` row exists — a malformed row wouldn't raise, it would silently produce a wrong/negative `horizon_minutes`. [backend/adapters/postgres/scenario_projection.py:88-95] — not reachable via governed fixture import.
- `_as_utc` doesn't special-case a DST fold/gap instant, and `_minute_offset` truncates toward zero rather than flooring. Fixture timestamps are minute-granular and the current Gate A fixture date ranges (early June, Australia/Sydney winter) never cross a DST boundary, so neither path is exercised today. Not reachable in either Gate A fixture. [backend/adapters/postgres/scenario_projection.py:124,134] — unreachable with current fixtures.
