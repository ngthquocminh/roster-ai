| session transcript state (client memory) | Ephemeral, never persisted; holds server-influenced outcome strings |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-17 | Information Disclosure | invalid deep-link :scenarioId | low | accept | No auth in v0.4 (REQUIREMENTS Out of Scope); an unknown id renders the terminal 404 view via useScenario's 404 (no cross-scenario data path). |
| T-02-18 | Tampering | transcript render of server strings | medium | mitigate | Entries render through TranscriptEntry's React-escaped JSX (plan 02-05); Editor only stores/forwards the response object, never dangerouslySetInnerHTML. |
| T-02-19 | Denial of Service | dependent-query gate | low | mitigate | OverridesList's query is enabled only on scenario success, so a 404 scenario never fires an independent overrides fetch. |
| T-02-SC | Tampering | dependency installs | low | accept | No package installs — composition of existing components + react-router. |

Block-on = high; no high-severity threats.
