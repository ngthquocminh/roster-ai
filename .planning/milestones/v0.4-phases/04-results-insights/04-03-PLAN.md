<objective>
Add the three TanStack Query hooks the Results view runs on: useRun (ungated status probe), useRunResult (dependent query gated on COMPLETED), and useRunInsights (button-triggered mutation-as-fetch). These extend the exact patterns already in the repo — useOverrides's `enabled` gate and useTriggerRun's useMutation — so the deep-linkable route never 409s and an insight failure stays structurally isolated.

Purpose: D-12 requires the route stay deep-linkable while /result 409s before COMPLETED; the enabled-gated dependent query is the mechanism. RES-05 requires an insight 502 never invalidate the schedule; modeling the insight fetch as an isolated useMutation (not a shared query) is the mechanism.
Output: useRun.ts, useRunResult.ts, useRunInsights.ts (+ tests).
</objective>
