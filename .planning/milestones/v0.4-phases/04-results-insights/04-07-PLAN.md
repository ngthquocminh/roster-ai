## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| deep-link URL → route | An arbitrary :runId (any status) can be deep-linked directly to the results route |
| insight fetch → results page | A 502 insight failure occurs within a mounted completed-run page |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-03 | Denial of Service (client availability) | insight 502 blast radius at the composition level | medium | mitigate | ResultsView mounts InsightPanel's isolated mutation alongside the query-fed sections; the RES-05 integration test asserts sibling sections survive a 502. |
| T-04-06 | Tampering (correctness) | /result fetched before COMPLETED (409) | low | mitigate | useRunResult's `enabled` is wired to status === "COMPLETED"; a non-COMPLETED deep link renders the in-flight/FAILED branch, never the body. |
| T-04-08 | Information disclosure | FAILED run.error rendered verbatim | low | mitigate | run.error renders as a plain JSX text child (Phase 3's established treatment); no raw-HTML sink; the fallback copy is used when error is empty. |
</threat_model>
