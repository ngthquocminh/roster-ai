<objective>
Empirically calibrate the four soft-override penalty weights against the committed
full-week fixture and lock the pass/fail signal into real-engine regression tests
— plus fold in the WR-05 degeneracy test that exercises the real solver. This is a
self-contained slice that needs no API key and no provider changes: it uses the
real CP-SAT engine and directly-constructed `OverrideCall`s.

Purpose: ENG-04 ("overrides enter the correct lexicographic round with calibrated
penalty weights — respected, but not dominating the cost objective") and folded
WR-05 (real-engine ENG-05 degeneracy detection).
Output: `backend/scripts/calibrate_penalties.py`, `backend/tests/test_penalty_calibration.py`,
and calibrated values in `backend/config/constants.py`.
</objective>
