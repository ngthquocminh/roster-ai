## Configuration

**Environment — Backend:**
- Loaded via `backend/settings.py` from `.env` file and OS environment
- Settings object: `Settings` dataclass (frozen, immutable)
- **Required variables:**
  - `ROSTERAI_DB` - SQLite database file path (default: `backend/var/rosterai.db`)
  - `ROSTERAI_DATA_DIR` - Input fixture directory (default: `<repo-root>/data`)
- **LLM Provider Configuration:**
  - `LLM_PROVIDER` - Provider name: `"stub"` (default, no API), `"gemini"`, or `"openrouter"`
  - `LLM_MODEL` - Model ID for selected provider (default: `"gemini-2.5-flash"` for Gemini)
  - `GEMINI_API_KEY` - Google Gemini API key (required if `LLM_PROVIDER=gemini`)
  - `OPENROUTER_API_KEY` - OpenRouter API key (required if `LLM_PROVIDER=openrouter`)
  - `OPENROUTER_MODEL` - Model ID for OpenRouter (default: `"openai/gpt-oss-20b:free"`)
- **CORS Configuration:**
  - `CORS_ORIGINS` - Comma-separated browser origins allowed to call this API (default: `"http://localhost:5173,http://localhost:4173"`)

**Environment — Frontend:**
- Loaded via Vite's `import.meta.env` at build time and runtime
- **Required variables:**
  - `VITE_API_BASE_URL` - Backend API origin (e.g., `"http://localhost:8000"` or production URL)
  - Fails loudly at module load in `src/lib/env.ts` if not set
- `.env` file not committed; copy from `frontend/.env.example` and customize

**Build:**
- **Backend:**
  - Entry point: `backend/api/main.py:26` (FastAPI app)
  - CLI entry: `backend/run.py:53` (synchronous solve execution)
  - No build step required; runs directly via `uvicorn`
  
- **Frontend:**
  - Build command: `npm run build` (executes `tsc -b && vite build`)
  - Output: `frontend/dist/` directory (static assets)
  - Dev server: `npm run dev` (runs Vite dev server with HMR)
  - Type check: `npm run typecheck` (runs `tsc --noEmit`)

**Code Generation:**
- OpenAPI Schema → TypeScript Types:
  - Backend exports OpenAPI schema at `/openapi.json` endpoint (FastAPI built-in)
  - Export: `npm run codegen:export` (runs `backend/scripts/export_openapi.py`)
  - Generate: `npm run codegen:types` (runs `openapi-typescript` to produce `src/api/schema.d.ts`)
  - Full pipeline: `npm run codegen` (export + generate)

## Platform Requirements

**Development:**
- Python 3.10, 3.11, or 3.12 (backend)
- Node.js 18+ (frontend)
- uv package manager (backend)
- npm or Node's package manager (frontend)
- SQLite 3 (built into Python 3.x)
- Platform: Linux, macOS, or Windows (including WSL2 for OR-Tools compatibility)

**Production:**
- **Frontend:**
  - Static file hosting (e.g., AWS S3 with CloudFront CDN)
  - No server runtime required; output is pre-built static assets
  
- **Backend:**
  - Container runtime (Docker) targeting AWS ECR + App Runner/ECS/EC2
  - Python 3.10–3.12
  - SQLite database file (local WAL mode currently; migration path to EFS or RDS)
  - 1 CPU core minimum for solving, more for concurrent requests
  - Memory: 512 MB minimum; 1-2 GB recommended for concurrent solves

**Deployment:**
- **Frontend:** S3 + CloudFront (static content delivery network)
- **Backend:** Docker container on AWS App Runner / ECS / EC2 (not Lambda — CP-SAT solves are CPU-heavy and long-running)
- Database: SQLite locally; future migration to RDS or EFS for distributed deployments
