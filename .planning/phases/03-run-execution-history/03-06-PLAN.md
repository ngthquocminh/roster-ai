Close gap G-03-1 (RUN-04): the Run History table's Created/Started/Finished
columns render backend timestamps verbatim — e.g. `2026-07-18T15:53:53.702354+00:00`
(32 chars) — inside `whitespace-nowrap` cells within a `table-fixed` layout whose

  <name>Task 1: Add formatTimestamp utility (pure, deterministic, timezone-safe)</name>
  <files>frontend/src/lib/formatTimestamp.ts, frontend/src/lib/formatTimestamp.test.ts</files>
  <behavior>
    - formatTimestamp("2026-07-18T15:53:53.702354+00:00") returns "2026-07-18 15:53"
    - formatTimestamp("2026-07-18T10:00:00Z") returns "2026-07-18 10:00"
    - formatTimestamp("2026-07-18T09:00:05.5+00:00") returns "2026-07-18 09:00"
    - formatTimestamp("not-a-date") returns "not-a-date" (unrecognized shape falls back to the input, never throws)
    - formatTimestamp("") returns "" (empty passes through unchanged)
  </behavior>
  <action>
    Create `frontend/src/lib/formatTimestamp.ts` exporting a single pure function
    `formatTimestamp(value: string): string`. It extracts the calendar date and the
    hour:minute from an ISO-8601 UTC timestamp and returns a fixed-width
    `YYYY-MM-DD HH:MM` string (16 characters) — the UTC wall-clock exactly as the
    backend emitted it (backend stamps `datetime.now(timezone.utc).isoformat()`, so
    the leading date+time portion is already UTC; do NOT shift the instant).

    Determinism is mandatory: the function MUST NOT use locale-default
    `toLocaleString` / `toLocaleDateString` / `toLocaleTimeString`, because those read
    the host machine's timezone and locale and would make jsdom tests machine-dependent
    and flaky. Implement it by matching/slicing the leading `YYYY-MM-DDTHH:MM` portion
    of the ISO string (a regex capturing the date group and the HH:MM group, joining
    them with a single space). This works uniformly for both the `Z`-suffixed form and
    the `+00:00`-offset form and drops the seconds, microseconds, and offset noise.

    Defensive fallback: if the input does not match the expected ISO shape, return the
    input unchanged (mirroring runStatus.ts / toolLabels.ts fallback discipline — never
    throw, never emit `Invalid Date`). Keep it pure with no React/JSX imports, and give
    it a module-level docstring explaining it exists to keep the fixed-width Run History
    columns legible (per gap G-03-1 / RUN-04).

    Write `frontend/src/lib/formatTimestamp.test.ts` first (RED) with the cases listed
    in this task's behavior block, then implement until green.
  </action>
  <verify>
    <automated>cd frontend && npm test -- src/lib/formatTimestamp.test.ts</automated>
  </verify>
  <done>formatTimestamp shortens the real 32-char microsecond+offset timestamp to "2026-07-18 15:53", shortens the Z-suffixed form, and returns unrecognized input unchanged; its unit test passes.</done>
</task>
