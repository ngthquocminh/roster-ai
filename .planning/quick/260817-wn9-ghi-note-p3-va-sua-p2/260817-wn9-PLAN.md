## Task 2 — P2: Gate A chạy lại được hai lần liên tiếp

**Vấn đề:** `resolve_code_binding()` từ chối cây git bẩn (`evidence_binding.py:159`), nhưng
`gate_a_readiness.main()` ghi ra `evidence/gate-a-readiness.json` (`:596-606`). Chạy lần 1 →
cây bẩn → lần 2 chết bằng `DirtyTreeError`. Công cụ tự làm bẩn đúng điều kiện nó đòi hỏi.

**Nguyên tắc đã chốt với user:** bẩn vì *code chưa commit* → phải từ chối. Bẩn vì *chính file
output mà lệnh này sắp ghi đè* → vô hại; commit được ghi lại vẫn mô tả đúng code đã đo.

**Files:**
- `backend/scripts/evidence_binding.py` — `working_tree_status()` nhận `ignore_paths`;
  `resolve_code_binding()` và `resolve_bindings()` truyền xuyên xuống
- `backend/scripts/gate_a_readiness.py` — `main()` truyền output path + staging `.tmp`
- `backend/tests/test_evidence_binding.py` — hai test

**Action:**
1. `working_tree_status(repo_root, *, ignore_paths: frozenset[str] = frozenset())` — lọc bỏ
   `ignore_paths` khỏi danh sách offending **trước khi** tính `dirty`. Chuẩn hoá path giống
   cách porcelain in ra (dấu `/`, tương đối repo root).
2. Guard "chỉ miễn trừ khi đó là file bẩn duy nhất" **tự có sẵn** từ bộ lọc: lọc xong nếu
   danh sách rỗng thì `dirty=False`; còn file nào khác bẩn thì nó vẫn nằm đó và vẫn ném.
3. Ghi nhận sự miễn trừ ra report bằng `binding_scope`, **chỉ khi** thực sự có miễn trừ.
   `working_tree_dirty` vẫn là `false` — đúng, vì phép đo tái lập được từ commit đã ghi.
4. Không đụng `audit_evidence_file()`; không dùng `git stash`; giữ nguyên `--code-from`.

**Verify (red-then-green, chuẩn A2 của retro):**
- Cây chỉ bẩn mỗi output path → resolve thành công, `working_tree_dirty: false`, có `binding_scope`
- Cây bẩn output path **+ một file `.py`** → vẫn `DirtyTreeError`
- Chứng minh đỏ: đổi bộ lọc thành bỏ qua *mọi* path → test thứ hai phải đỏ
